Jogo: Ecossistema em Equilíbrio

Conceito: O jogador deve combinar organismos corretamente para formar relações ecológicas válidas.

  1. Cartas aparecem com imagens de organismos (ex: abelha, flor, leão, zebra).
  2. O jogador clica nos organismos para formar um par.
  3. O sistema valida se a relação ecológica está correta.
  4. Pontuação por acertos.
